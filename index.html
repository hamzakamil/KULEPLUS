Mevzuat uyumluluğu

Türkiye şartlarına göre kuruldu

  • ✓ e-Fatura / e-Arşiv / e-İrsaliye — GİB onaylı entegratör adapter’ı
  • ✓ TDHP şablonu; şirkete özel alt hesap eklenebilir
  • ✓ KDV — tarih aralıklı oran tablosu, tevkifat/istisna kodları
  • ✓ KVKK — aydınlatma, saklama/imha, ihlal prosedürü
  • ✓ UTF-8, tr-TR yerelleştirme, İ/ı duyarlı, 1.234,56 biçim
  • ✓ WCAG 2.1 AA erişilebilirlik hedefi

Mevzuat bilgileri 5 Ekim 2026 itibarıyla kamuya açık kaynaklardan derlenmiştir; canlıya almadan önce mali müşavir + hukukçu doğrulaması gerekir.

Sık sorulan sorular

Merak edilenler

Ücretsiz paket gerçekten süresiz mi?

Evet. Demo süresi yoktur; yeni kayıt olan herkes süresiz ücretsiz başlangıç paketine sahip olur (Cari veya Stok). Diğer modüller satın alınır.

e-Fatura, KDV gibi Türkiye mevzuatına uyumlu mu?

Platform; e-Fatura, e-Arşiv, e-Defter, KDV, Tek Düzen Hesap Planı ve KVKK gerekliliklerine göre tasarlanmıştır. e-Belge gönderimi GİB onaylı özel entegratör REST API üzerinden yapılır.

Verilerim dışa aktarılabilir mi?

Evet — veri rehin alınmaz. Her planda tam dışa aktarma (ZIP: manifest + CSV dosyaları + yüklenen dosyalar) açıktır. Paket düştüğünde modül salt okunur olur, veri silinmez.

Mali müşavirim de sistemi kullanabilir mi?

Evet. Mali müşavir farklı şirketlere ayrı üyeliklerle erişir; her şirketin yetkisi bağımsızdır. Varsayılan yetki salt okuma + dışa aktarmadır.
