# ADR-0002: UUID v7 Birincil Anahtar Standardı

**Tarih:** 5 Ekim 2026
**Durum:** Kabul
**İlgili:** GOVERNANCE §3 · SPEC §0.1 · ROADMAP Faz 0 kabul kriteri

## Bağlam
Çok kiracılı sistemde birincil anahtarlar hem dağıtık üretime uygun hem sıralanabilir
hem de UUID formatında olmalıdır. PostgreSQL `gen_random_uuid()` v4 üretir (sırasız).

## Karar
- Birincil anahtar standardı **UUID v7**'dir.
- Üretim **uygulama tarafında** yapılır (`packages/shared/id` → `newId()`); DB default'ı olarak
  `gen_random_uuid()` kullanılmaz.
- Zaman sıralılık zorunludur: ardışık iki ID'de ikincisi büyüktür (yüzde yüz test edilir).

## Alternatifler
| Alternatif | Neden reddedildi |
|------------|------------------|
| DB `gen_random_uuid()` (v4) | Sırasız; index fragmentasyonu ve sıcak nokta riski |
| bigint sequence | Kiracı bazında bilgi sızdırır (sayılabilir ID); dağıtık üretimde çakışma |
| ULID | UUID ekosistem uyumluluğu düşük; UUID v7 RFC 9562 standardı |

## Sonuçlar
- ➕ Sıralı index, dağıtık güvenli üretim, tek fonksiyon
- ➖ 128 bit alan maliyeti (kabul edilebilir)

## Kapanış Kriteri
`packages/shared/tests/id.test.ts`: 1000 ardışık ID sıralı + v7 formatı + `idTimestamp` — hepsi yeşil.
