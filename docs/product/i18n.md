# i18n Sözleşmesi

**Durum:** İskelet — Faz 2'de doldurulacak
**Başlangıç dili:** Sadece TR (vue-i18n altyapısı hazır)

## Anahtar Kuralı
- Format: `<modül>.<alan>.<alt_alan>` (ör. `auth.login.title`)
- Dosya yapısı: modül başına JSON (`locales/tr/auth.json`, `locales/tr/contacts.json`)

## Backend Hata Kodu → Frontend Çevirisi
Backend her zaman `code` döner; frontend `t('errors.' + code)` ile çevirir.
Örnek: `PERIOD_LOCKED` → `errors.PERIOD_LOCKED`

## Tarih/Sayı Formatı
- Tarih: `Intl.DateTimeFormat('tr-TR')`
- Sayı: `Intl.NumberFormat('tr-TR')`
- Para: `Intl.NumberFormat('tr-TR', { style: 'currency', currency: 'TRY' })`
